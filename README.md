## Problem Statement

To perform Exploratory Data Analysis (EDA) on the Amazon Prime dataset using Python to understand the distribution, trends, and characteristics of movies and TV shows available on the platform.

## Summary

The Amazon Prime EDA Project is a data analysis and visualization project developed using Python to explore and understand the content available on the Amazon Prime platform. The main purpose of this project is to perform Exploratory Data Analysis (EDA) on an Amazon Prime dataset and identify useful patterns, trends, distributions, and characteristics of movies and TV shows.
